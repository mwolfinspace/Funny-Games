How to Play

  • Camera Controls
    • Left Mouse + Drag: Rotate camera.
    • Right Mouse + Drag: Pan camera.
    • Scroll Wheel: Zoom in / out.
  • Cube Interaction
    • Double-click a cube: Select it to move.
    • Press 'R' key: Rotate the selected cube.
    • Click on another cube's face: Place the selected cube.
    • Press 'Esc' key: Cancel the move.
  • Controls
    • 🏠 Menu: Return to the main page.
    • ➖ / ➕: Decrease / Increase the number of cubes.
    • 🔀 Random: Generate a new random shape.
    • 🖼️ Export: Export the current view as a PNG image.
