How to Play

This is NOT a normal memory game.

You must find two lions that are completely different.

  • 🎨 Color: Must be different.
  • 🦁 Mane: Must be different.
  • 〰️ Tail: Must be different.

✅ Correct Match (Example)

≠
Yellow ≠ Purple
Round ≠ Edgy
Square ≠ Circle

❌ Wrong (Bad Match)

=
Yellow = Yellow 🚫
Round ≠ Edgy
Square ≠ Circle

💾 Save & Challenges

Use the code system to save your game or challenge a friend.

  • SEED: A short, case-sensitive code (e.g., LION) to start a specific shuffle.
  • SAVE: A long code that stores your exact progress (revealed and matched cards).
