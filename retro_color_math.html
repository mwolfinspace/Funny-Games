🎮 Gameplay

This is a 2-stage game where you first create a secret math equation, and then try to guess it based on input/output results.

STAGE 1: Set Secret Equation

1. Create a math equation using numbers, operators (+, -, x, :).
2. You MUST include the special variable `🟩` in your equation.
3. Press the ✅ ENTER button to lock it in.

STAGE 2: Guess the Equation

1. The screen will now accept number inputs.
2. Enter any number and press ✅ ENTER to see what the result is based on your secret equation.
3. Analyze the input/output pairs in the history pane.
4. When you think you know the secret equation, type it into the input field (using `🟩`) and press 🔍 CHECK.
5. If you are correct, you win! 🎉

⚙️ Control Buttons

  • 🏳️ GIVE UP: Reveals the secret equation and ends the game.
  • 🔍 CHECK: Checks if your equation guess is correct.
  • ✅ ENTER: Locks the secret equation (Stage 1) or submits a number for testing (Stage 2).
  • 🔄 RESET: Resets the entire game to Stage 1.
  • 💡 HINT: Gives a small hint about the secret equation in Stage 2.
  • 🎲 QUICK: In Stage 1, instantly generates a random equation for you.

⌨️ Keyboard Shortcuts

  • Numbers (0-9): Input numbers.
  • Operators (+, -, *, /): Input operators.
  • Shift + / (?): Input the `🟩` variable.
  • . (period): Input a decimal point.
  • Enter: Functions as the ✅ ENTER button.
  • Spacebar: Functions as the = (calculate) button or the 🔍 CHECK button if `🟩` is in the input.
  • Backspace: Deletes the last character. Hold to clear input.
  • Escape: Functions as the 🔄 RESET button or closes this help popup.
  • ` (backtick): Instantly generates and enters a random equation to start Stage 2.
