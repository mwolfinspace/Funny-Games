How to Play

1. Find a "Roar" Set

Pick 3 cards. For each feature (Color, Mane, Tail), the cards must be either ALL THE SAME or ALL DIFFERENT.

✔ GOOD

(Colors are different, Manes are same, Tails are same)

✖ BAD

(Two Yellows, One Purple = Not all same, not all different)

2. Save & Challenges

SEED: Use Letters, Numbers, or Symbols (e.g., LION vs LION!). Games are case-sensitive!

SAVE: Long code (e.g. "4k91Z..."). Copy this to save your progress.

3. Roar Mode 🦁

When ON: Finding a set triggers a special animation. Tap the screen to collect the cards.
