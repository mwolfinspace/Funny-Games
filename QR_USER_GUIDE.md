# QR Code Feature - User Guide

## How to Use the QR Code Feature

### Generating & Sharing a Game

1. **Start or play a nonogram puzzle**
2. **Click the QR button** (next to the seed display at bottom-left)
   - Look for the QR icon button to the right of the "Seed: ..." display
3. **Share Your Game:**
   - **Copy Link**: Click "🔗 Copy Link" to copy the shareable URL to clipboard
   - **Download QR**: Click "⬇️ Download QR" to save the QR code as an image
   - **Share with others**: Send them the link or QR image

### Accessing a Shared Game

**Method 1: Using the Link**
1. Click or paste the shared link in your browser
2. The page automatically loads with:
   - The same puzzle
   - All your progress (filled and crossed cells)

**Method 2: Using the QR Code**
1. Scan the QR code with your phone or QR code reader
2. It takes you to the game with all your progress

## What Gets Saved & Shared

✓ **The Puzzle** - Same puzzle seed  
✓ **Your Progress** - All filled and crossed cells you've marked  
✓ **Zoom Level** - The zoom/scale you were using

## Tips & Tricks

💡 Share an incomplete puzzle with a friend to challenge them to finish it  
💡 Save your progress by bookmarking the shared link  
💡 Use the QR code to quickly open your game on your phone  
💡 The seed display still works for copying just the puzzle seed without your progress  

## Troubleshooting

**Q: The game won't load from the link**  
A: Make sure you're using the full URL that includes `#` before the code

**Q: The QR button isn't showing**  
A: Make sure you're using the latest version of Nonogram.html

**Q: Can't copy the link**  
A: Your browser needs to support the Clipboard API (all modern browsers do)

**Q: The progress isn't restoring**  
A: Try refreshing the page after clicking the link. Clear browser cache if needed.
