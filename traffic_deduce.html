🚦 How to Play Sign City

🎯 Goal

Trucks enter the city from numbered gateways. Each sign (🟡 🟦 🔺) tells the truck what to do — turn left, go straight, or turn right. Solve the puzzle depending on the mode you're in.

🎮 Three Modes

  • Mode 1 · Predict the Exit: Build the map and predict which gateway each truck exits from. Place End markers, then Play to verify.
  • Mode 2 · Decode the Meaning: The map is set up. Figure out what each sign means. Click pills to assign, right-click to scratch out. Some maps hide a few signs on the route — place the correct ones too. Lock when ready, then Play.
  • Mode 3 · Build the Signs: Meanings and start/end pairs are given. Place signs on intersections to route trucks correctly.

🛠 Building Tools

  • Click a tool above the map to arm it (Yellow, Blue, Red, U-turn, Start, End, Erase).
  • Click on the map to place; right-click to remove.
  • Press Esc or click the active tool again to disarm.
  • Empty intersections = truck goes straight.

💊 Meaning Pills

  • Left-click a pill to assign that meaning to the symbol.
  • Right-click to scratch it out — a thinking aid, doesn't affect logic.
  • Each meaning (Left / Straight / Right) is used by exactly one symbol.

🚗 Simulation

  • Press ▶ to launch trucks from each Start gateway in round-robin order.
  • Adjust speed with 🐢 / 🐇 and number of cars with − / +.
  • Track lines appear in each Start's color.
  • Match the End number to the Start number for a correct arrival.

🌱 Seeds

Every map has a seed code. Click the seed display to copy it. Paste into the seed box and click 📥 to recreate the exact puzzle.

⌨️ Keyboard

  • Space — Play / Pause
  • R — Reset
  • 1 / 2 / 3 — Switch modes
  • Esc — Exit current tool
